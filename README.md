# Precedent

Your team's decisions, enforced: for people and AI coding agents.

Precedent is an Atlassian Forge app built for **Codegeist 2026**. It turns decisions scattered across Confluence pages and Jira comments into a living register. It flags new work that contradicts a past decision, in Jira, in Rovo, and in AI coding tools over MCP.

> Work in progress. Setup and judge instructions will land in `docs/` before submission.

## Repository layout

| Path | What lives there |
| --- | --- |
| `app/` | The Forge app (manifest, backend functions, UI) |
| `skills/` | Open-source `skill.md` for third-party agents using the MCP server |
| `scripts/` | Dev and deploy helpers |
| `docs/` | Judge setup guide, architecture notes |
